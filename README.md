# Mini‑Projeto: Festa em Cena (versão júnior, sem Pandas)

## O que faz
Programa em Python que lê `halloween_vendas.csv`, limpa e valida os dados usando só a biblioteca padrão e gera `REPORT.md`.

## Arquivos
- `main.py` — executa tudo e cria `REPORT.md`.
- `funcoes.py` — funções simples de limpeza e validação.
- `halloween_vendas.csv` — coloque aqui.
- `REPORT.md` — gerado automaticamente.
- `video_script.txt` — roteiro curto (opcional).
